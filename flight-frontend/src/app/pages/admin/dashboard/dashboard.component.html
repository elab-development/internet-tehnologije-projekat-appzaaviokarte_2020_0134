Welcome to the Admin Home Page!

Here, you have access to the key features of the system, enabling you to manage all aspects of the platform efficiently.

Below is an overview of what you can do on each page:

  • Airports: Manage the list of airports available in the system. You can add new airports, update existing information, or remove outdated entries.
  • Flights: Oversee flight details, including schedules, destinations, and availability. This section allows you to create, edit, or delete flight records.
  • Users: Manage user accounts registered on the platform. You can view user details, update their permissions, or deactivate accounts if needed.
  • Bookings: Review and manage customer bookings. Here, you can monitor reservations or cancel bookings as required.

Explore these features through the navigation bar above, and feel free to reach out to support if you need assistance.

Thank you for keeping the system running smoothly!
